# Reethusri - Cybersecurity Mini Projects

This repository is structured for GitHub Pages.

## Files
- `index.html` — portfolio homepage
- `mini-project-4/index.html` — OSINT report
- `mini-project-5/index.html` — Network Discovery report
- `mini-project-6/index.html` — AI-Assisted Attack Surface report

## Publish with GitHub Pages
1. Create a GitHub repository.
2. Upload all files and folders from this package, keeping the folder structure.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. Wait for deployment. Open the Pages URL shown in Settings → Pages.

The homepage is the repository's root `index.html`. Each report has its own `index.html` inside its project folder.
